# SkillSwap

[![Made with Angular](https://img.shields.io/badge/frontend-Angular-red?logo=angular)](https://angular.io/)
[![Backend .NET](https://img.shields.io/badge/backend-.NET%20Core-blue?logo=dotnet)](https://dotnet.microsoft.com/)
[![Database PostgreSQL](https://img.shields.io/badge/database-PostgreSQL-336791?logo=postgresql)](https://www.postgresql.org/)

**SkillSwap** — це веб-застосунок для бартерного обміну навичками та послугами між людьми.  
Проєкт дає можливість користувачам створювати профілі, додавати свої навички та інтереси, знаходити партнерів для обміну знаннями, спілкуватися через чат у реальному часі й залишати відгуки. Система також передбачає інструменти для модерації та адміністрування.
