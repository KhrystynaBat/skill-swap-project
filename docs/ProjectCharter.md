# Project Charter / Product Vision

**For:** SkillSwap

**Version:** 0.1

**Prepared by:** Olesia Baidala & Khrystyna Bat


##  1. Проблематика

Сьогодні багато людей хочуть навчитися новим навичкам або отримати певну допомогу, але стикаються з такими проблемами:

- навчальні курси та послуги часто є занадто дорогими;
- складно знайти людину, яка готова поділитися знаннями чи навичками;
- можливості для неформального навчання розпорошені між різними платформами та чатами;
- відсутній зручний централізований сервіс для обміну навичками без фінансових витрат;
- користувачам бракує безпечного середовища для пошуку партнерів, спілкування та підтвердження домовленостей.

З іншого боку, багато людей мають корисні знання, досвід або практичні вміння, але не мають зручного способу запропонувати їх іншим і водночас отримати щось цінне у відповідь.

**SkillSwap** вирішує цю проблему шляхом створення єдиної платформи, де користувачі можуть обмінюватися навичками напряму, швидко знаходити відповідних партнерів і будувати взаємовигідну співпрацю.


## 2. Цілі проєкту

### Бізнес-цілі

1. Створити вебплатформу для бартерного обміну навичками між людьми без грошових транзакцій.
2. Сформувати активну спільноту, де кожен учасник є одночасно учнем і вчителем.
3. Побудувати систему репутації та відгуків для підвищення довіри між користувачами.
4. Забезпечити зростання кількості зареєстрованих користувачів та успішно завершених обмінів.

### Продуктові цілі

1. Реалізувати інтелектуальний алгоритм підбору партнерів на основі навичок та інтересів.
2. Забезпечити зручний цикл взаємодії: реєстрація → профіль → пошук → домовленість → обмін → відгук.
3. Реалізувати чат у реальному часі для комунікації між користувачами.
4. Підтримати адаптивний інтерфейс для роботи через мобільний браузер.
5. Реалізувати систему модерації для підтримки якості та безпеки спільноти.


## 3. Очікувані результати

Після реалізації MVP платформа повинна забезпечувати такі можливості:

### Для користувачів:
- реєстрація та авторизація
- створення та редагування профілю
- додавання навичок, якими користувач може поділитися
- додавання навичок або послуг, які користувач хоче отримати
- пошук користувачів за ключовими словами та фільтрами
- автоматичний підбір можливих партнерів
- отримання сповіщень про нові збіги
- обмін повідомленнями у внутрішньому чаті
- узгодження деталей співпраці та часу взаємодії
- підтвердження завершення обміну
- залишення відгуків і перегляд рейтингу
- перегляд історії обмінів

### Для адміністратора:
- перегляд та керування користувачами
- блокування небажаних або некоректних користувачів
- модерація контенту
- керування категоріями навичок
- перегляд аналітики активності системи


## 4. Критерії успіху

Проєкт вважатиметься успішним, якщо будуть виконані такі умови:

### Функціональні критерії:
- користувач може успішно зареєструватися та увійти в систему
- користувач може створити профіль і додати власні навички та інтереси
- система коректно виконує пошук і підбір партнерів
- чат працює в режимі реального часу
- користувачі можуть підтверджувати обмін та залишати відгуки після його завершення
- адміністратор має можливість керувати користувачами та контентом

### Технічні критерії:
- час відповіді на основні дії (вхід, пошук, повідомлення) не перевищує **3 секунд**
- система залишається доступною не менше 90% часу (uptime)
- система коректно обробляє конкурентні сценарії (одночасні запити на обмін, паралельні пошукові запити)
- паролі зберігаються у хешованому вигляді, передача даних — через захищене з'єднання HTTPS
- система захищена від основних веб-вразливостей (SQL Injection, XSS, CSRF)
- інтерфейс коректно відображається в актуальних версіях браузерів Chrome, Safari, Firefox

### Продуктові метрики:
- кількість зареєстрованих користувачів
- кількість створених профілів з навичками
- кількість завершених обмінів
- кількість активних чатів
- середній рейтинг користувачів
- кількість залишених відгуків


## 5. Цільова аудиторія

Основною цільовою аудиторією платформи **SkillSwap** є:

- Студенти
- Фрілансери
- Молоді спеціалісти
- Невеликі спільноти та активні користувачі


## 6. Ключові стейкхолдери

- Користувачі - використовують платформу для обміну навичками та послугами 
- Команда розробки - проєктує, реалізує та підтримує систему 
- Адміністратор - забезпечує порядок, безпеку та контроль контенту
- Замовник - оцінює результат


## 7. Обмеження проєкту

### Технічні обмеження

- Реалізація у вигляді вебзастосунку 
- Підтримка лише актуальних версій основних браузерів
- Локалізація лише українською та англійською мовами

### Архітектурні обмеження

- Frontend: Angular SPA
- Backend: .NET Core (C#), REST API + SignalR
- База даних: PostgreSQL
- Кеш та сесії: Redis
- Контейнеризація: Docker

### Ресурсні обмеження

- Обмежений склад команди розробки
- Обмежений часовий ресурс

### Регуляторні обмеження

- Дотримання вимог щодо обробки та зберігання персональних даних
- Дотримання правил модерації контенту та політик платформи


## 8. Product Vision

Проєкт **SkillSwap** передбачає створення онлайн-платформи для обміну навичками між людьми, яка об’єднує користувачів, що хочуть навчатися та ділитися знаннями безоплатно. 
Платформа підтримує процеси пошуку партнерів, комунікації, домовленостей про співпрацю та оцінювання результатів обміну.

### Потреби

- Доступ до платформи для безкоштовного обміну навичками  
- Зручний пошук людей з потрібними знаннями або досвідом  
- Можливість презентувати власні навички та інтереси  
- Безпечне середовище для комунікації між користувачами  
- Система рейтингів і відгуків для формування довіри  
- Інструменти для організації та підтвердження обміну

### Продукт

**SkillSwap** — це вебплатформа для обміну знаннями та навичками, яка включає:

- створення та редагування профілів користувачів  
- додавання навичок і інтересів  
- пошук та підбір партнерів для обміну  
- чат для комунікації між користувачами  
- систему підтвердження обміну  
- систему оцінок і відгуків  
- адміністративну панель для модерації

### Бізнес цілі

- розробити та запустити робочу версію платформи
- сформувати спільноту активних користувачів
- побудувати репутаційну систему як основу довіри між учасниками
- закласти архітектурну основу для подальшого розширення функціоналу
